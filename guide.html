Weather Dashboard: розбір ООП-версії

Сервер погоди на чистому Node.js і Leaflet-фронтенд, переписані з функцій-фабрик на класи: доменні value object-и, абстрактні клієнти, контролери й джерела шарів карти, ієрархія помилок та ін'єкція залежностей. Нижче видно, що робить кожен клас, чому код розкладено саме так і чим перевірено, що поведінка не змінилась.

1. Що змінилось і навіщо

Раніше кожен шар був набором функцій-фабрик: createWeatherService(), createGridService(), createOpenWeatherClient(), createWeatherController(). Усередині жили замикання з прихованими змінними, а дані між шарами ходили звичайними об'єктами. Валідація (parseTile, перевірка міста, країни, години) розсипана по сервісах. Фронтенд був одним файлом із глобальними змінними (map, marker, weatherLayer, frameSeq…). Тепер усюди класи, кожен із однією роллю. API не змінилось: 37 з 41 запиту до старої й нової версії дають байт у байт однакові відповіді, а решта чотири відрізняються лише закінченнями рядків статичних файлів чи навмисно переписаним app.js (див. «Що перевірено»).

3. ООП-ідеї на цьому коді

ІдеяДеПростими словами
Інкапсуляція#apiKey у OpenWeatherClient, #snapshot / #inflight у GridService, #names у CountryRegistry; на фронтенді #map, #layer, #frameSeqвнутрішній стан сховано справжніми приватними полями #; ззовні лише методи. Ключ API не потрапить у лог чи JSON випадково.
НаслідуванняApiClient → 2 клієнти; Controller → 4 контролери; Frame → WindFrame, PrecipitationFrame; LayerSource → TileSource, FrameSource → …; AppError → 4 помилкиспільне живе в предку, нащадок додає лише своє.
Абстрактний класApiClient, Controller, Frame, LayerSource: у конструкторі if (new.target === Клас) throwJavaScript не має слова abstract, тому заборону створювати «заготовку» робимо перевіркою. Тест це підтверджує.
Шаблонний методApiClient.request(), Controller.handle()предок задає порядок кроків, а нащадок перевизначає лише окремий крок (errorForStatus, respond).
ПоліморфізмJSON.stringify(frame) викликає toJSON() нащадка; Router викликає handle() і контролера, і StaticHandler; WeatherMap викликає source.createLayer(), не знаючи, вітер це чи тайлиодин виклик — різна поведінка залежно від того, який об'єкт перед нами. Місце, що викликає, не перевіряє тип.
Value objectCoordinate, CityQuery, TileRequest, ForecastHour, WindVector, Grid: Object.freeze(this)маленький незмінний об'єкт, який перевіряється при створенні (parse): якщо він існує, він правильний.
Композиція та ін'єкція залежностейnew WeatherService({ client }), new GridService({ client, grid, now, sleep }), new Router({ fallback }), new Timeline({ onChange })об'єкт отримує потрібні частини ззовні, а не створює їх сам. У тестах підставляються фейки, а на фронтенді Timeline не знає про карту.
Статичні фабрикиCityQuery.parse, Weather.fromApi, WindFrame.of, CountryRegistry.europe, WindVector.fromMeteoосмислена назва замість «голого» new з десятком аргументів.
Приватні поля # і тести

До #snapshot з тесту не дістатись, і це правильно: тести перевіряють поведінку (скільки запитів пішло в клієнт, що повернув сервіс), а не внутрішні змінні. Якщо переписати кеш інакше, тести лишаться зеленими.

4. Шлях одного запиту

Запит: GET /api/weather?city=kyiv&country=ua.

  1. WeatherApp приймає з'єднання й віддає req, res у Router.handle().
  2. Router розбирає URL (помилка розбору → 400), не-GET відсікає (405), за pathname знаходить контролер. Нічого не знайшлося — віддає запит StaticHandler.
  3. Controller.handle() викликає respond() нащадка у try/catch. WeatherController.respond() бере city і country з query і кличе weatherService.getWeather().
  4. WeatherService створює CityQuery.parse('kyiv', 'ua', countries): назва обрізана, країна → UA, невідома → ValidationError (400).
  5. Два запити паралельно (Promise.all): client.getCurrent(query) і client.getForecast(query). OpenWeatherClient збирає URL із ключем, а ApiClient.request() виконує fetch і перетворює збій на UpstreamError чи статус на помилку потрібного типу.
  6. ForecastBuilder.build() групує 40 записів по днях міста й повертає 3 DailyForecast; Weather.fromApi() перекладає чужий формат у наш.
  7. Controller.sendJson() робить JSON.stringify(weather): той викликає Weather.toJSON(), який фіксує порядок полів відповіді.
  8. Помилка на будь-якому кроці потрапляє в Controller.sendError(): AppError → статус із класу, усе інше → 500 без деталей.

Кадр вітру (GET /api/wind?hour=5) іде тим самим шляхом, але через FrameController і GridService.getWindFrame(). Він бере ForecastHour.parse, свіжий GridSnapshot (або завантажує сітку, див. розділ 8), знаходить індекс години й збирає WindFrame.

// Ієрархія помилок. Сервіси й клієнти кидають їх, а контролер перетворює на HTTP-відповідь:
// статус уже вшито в клас, тож нижні шари не знають про HTTP-відповіді.
//
//   Error
//    ├─ ConfigError              — неправильні налаштування (лише при старті, не HTTP)
//    └─ AppError (status)
//        ├─ ValidationError  400 — поганий ввід користувача
//        ├─ NotFoundError    404 — місто чи тайл не знайдено
//        ├─ RateLimitError   429 — вичерпано ліміт запитів
//        └─ UpstreamError    502 — проблема на боці зовнішнього API
export class AppError extends Error {
  constructor(message, status, options) {
    super(message, options);
    this.name = new.target.name; // імʼя реального класу: ValidationError, UpstreamError, ...
    this.status = status;
  }
}

export class ValidationError extends AppError {
  constructor(message, options) {
    super(message, 400, options);
  }
}

export class NotFoundError extends AppError {
  constructor(message, options) {
    super(message, 404, options);
  }
}

export class RateLimitError extends AppError {
  constructor(message, options) {
    super(message, 429, options);
  }
}

export class UpstreamError extends AppError {
  constructor(message, options) {
    super(message, 502, options);
  }
}

export class ConfigError extends Error {
  constructor(message, options) {
    super(message, options);
    this.name = 'ConfigError';
  }
}
src/controllers/Controller.jsєдине місце відповідей про помилки + шаблонний метод
// ШАР 1 — базовий Controller (HTTP-шар) і «шаблонний метод»: handle() задає порядок (спробувати → помилка у відповідь),
// а нащадок пише лише respond(): що саме відповісти. Жодної бізнес-логіки: «HTTP in → service → HTTP out».
import { AppError } from '../errors.js';

export class Controller {
  constructor() {
    if (new.target === Controller) throw new TypeError('Controller is abstract: use a subclass');
  }

  // ctx = { url, params }: url — розібраний URL запиту, params — групи з регулярного виразу маршруту
  async handle(req, res, ctx) {
    try {
      await this.respond(req, res, ctx);
    } catch (err) {
      this.sendError(res, err);
    }
  }

  // Те, що має написати нащадок
  async respond() {
    throw new Error(`${this.constructor.name} must implement respond()`);
  }

  sendJson(res, status, body) {
    res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
    res.end(JSON.stringify(body)); // для обʼєктів із toJSON (Weather, Frame…) форму визначає сам обʼєкт
  }

  sendError(res, err) {
    if (err instanceof AppError) return this.sendJson(res, err.status, { error: err.message });
    console.error(err); // непередбачена помилка — деталі лише в лог, клієнту загальне повідомлення
    this.sendJson(res, 500, { error: 'Внутрішня помилка сервера.' });
  }
}

// Налаштування застосунку. Створюються лише через fromEnv/load і перевіряються при створенні:
// немає ключа — програма не стартує, а не ламається пізніше з 401.
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { ConfigError } from './errors.js';

const ROOT = path.join(path.dirname(fileURLToPath(import.meta.url)), '..');

export class AppConfig {
  static PLACEHOLDER_KEY = 'your_api_key_here'; // значення з .env.example

  // Чиста функція від env: у тестах передаємо свій обʼєкт і не чіпаємо process.env
  static fromEnv(env = process.env, publicDir = path.join(ROOT, 'public')) {
    const apiKey = env.OPENWEATHER_API_KEY;
    if (!apiKey || apiKey === AppConfig.PLACEHOLDER_KEY) {
      throw new ConfigError('Немає OPENWEATHER_API_KEY. Скопіюй .env.example у .env і встав свій ключ.');
    }
    return new AppConfig({ apiKey, port: Number(env.PORT) || 3000, publicDir });
  }

  // Для запуску: спершу підвантажує .env (необовʼязковий), потім читає env
  static load() {
    try {
      process.loadEnvFile(path.join(ROOT, '.env')); // Node 20.12+
    } catch {
      // .env немає — залишаються змінні середовища системи
    }
    return AppConfig.fromEnv();
  }

  constructor({ apiKey, port, publicDir }) {
    this.apiKey = apiKey;
    this.port = port;
    this.publicDir = publicDir;
  }
}
  • Статус вшито в клас. Хто кидає new NotFoundError('…'), не думає про 404. Раніше кожне місце писало new AppError(404, '…'), і статус легко було переплутати.

import { ValidationError } from '../errors.js';

// Запит «місто + (необовʼязково) країна», який уже пройшов перевірку.
// Створити його можна лише через parse: якщо в руках CityQuery, назва й код країни правильні.
export class CityQuery {
  static MAX_LENGTH = 100;

  static parse(rawCity, rawCountry, countries) {
    const name = String(rawCity ?? '').trim();
    if (!name || name.length > CityQuery.MAX_LENGTH) {
      throw new ValidationError(`Вкажи назву міста (до ${CityQuery.MAX_LENGTH} символів).`);
    }
    return new CityQuery(name, countries.normalize(rawCountry)); // порядок: спершу місто, потім країна
  }

  constructor(name, country) {
    this.name = name;
    this.country = country; // '' — будь-яка
    Object.freeze(this);
  }
}
src/domain/CountryRegistry.jsбілий список країн із приватними полями
import { EUROPE_COUNTRIES } from '../data/europeCountries.js';
import { ValidationError } from '../errors.js';

// Довідник країн: код ISO → назва. Це «білий список»: до зовнішнього API потрапить лише код, який тут є.
// Дані ховаються в приватних полях, ззовні їх читають лише через методи.
export class CountryRegistry {
  #names;
  #list;

  constructor(names) {
    this.#names = Object.freeze({ ...names });
    // Для випадаючого списку: відсортовано за абеткою (українська колація)
    this.#list = Object.freeze(
      Object.entries(names)
        .map(([code, name]) => Object.freeze({ code, name }))
        .sort((a, b) => a.name.localeCompare(b.name, 'uk')),
    );
  }

  // Країни Європи (трансконтинентальні не включені)
  static europe() {
    return new CountryRegistry(EUROPE_COUNTRIES);
  }

  list() {
    return this.#list;
  }

  has(code) {
    return Object.hasOwn(this.#names, code);
  }

  // Рядок користувача → код у верхньому регістрі, '' (країну не вказано) або ValidationError
  normalize(raw) {
    const code = String(raw ?? '').trim().toUpperCase();
    if (code && !this.has(code)) throw new ValidationError('Невідома країна.');
    return code;
  }
}
src/domain/TileRequest.jsперевірка тайла до запиту назовні
import { ValidationError } from '../errors.js';

// Запит тайла карти, який уже пройшов перевірку: шар із білого списку, а координати плитки
// в межах сітки. У zoom z існує 2^z × 2^z тайлів (x, y від 0 до 2^z − 1).
export class TileRequest {
  static LAYERS = Object.freeze(['clouds_new', 'precipitation_new', 'wind_new', 'temp_new', 'pressure_new']);
  static MAX_ZOOM = 10;

  static parse({ layer, z, x, y }) {
    const [nz, nx, ny] = [z, x, y].map(Number);
    const side = 2 ** nz;
    const ok =
      TileRequest.LAYERS.includes(layer) &&
      Number.isInteger(nz) && nz >= 0 && nz <= TileRequest.MAX_ZOOM &&
      Number.isInteger(nx) && nx >= 0 && nx < side &&
      Number.isInteger(ny) && ny >= 0 && ny < side;
    if (!ok) throw new ValidationError('Некоректний тайл карти.');
    return new TileRequest(layer, nz, nx, ny);
  }

  constructor(layer, z, x, y) {
    this.layer = layer;
    this.z = z;
    this.x = x;
    this.y = y;
    Object.freeze(this);
  }
}

    return new Date((dt + tz) * 1000).getUTCHours();

    const today = ForecastBuilder.#localDate(Math.floor(nowMs / 1000), tz);

    for (const item of forecast.list) {
      const day = ForecastBuilder.#localDate(item.dt, tz);
      if (day === today) continue; // сьогодні показує блок «зараз»
      if (!byDay.has(day)) byDay.set(day, []);
      byDay.get(day).push(item);
    }

    return [...byDay.entries()].slice(0, this.#days).map(([date, items]) => this.#summarize(date, items, tz));
  }

  #summarize(date, items, tz) {
    const temps = items.map((i) => i.main.temp);
    const humidity = items.reduce((sum, i) => sum + i.main.humidity, 0) / items.length;
    // Іконка й опис — із запису, найближчого до полудня
    const noon = items.reduce((best, i) =>
      Math.abs(ForecastBuilder.#localHour(i.dt, tz) - 12) < Math.abs(ForecastBuilder.#localHour(best.dt, tz) - 12) ? i : best,
    );
    return new DailyForecast({
      date,
      min: Math.min(...temps),
      max: Math.max(...temps),
      humidity: Math.round(humidity),
      icon: noon.weather[0].icon.replace('n', 'd'), // нічна іконка на картці дня виглядає дивно
      description: noon.weather[0].description,
    });
  }
}

// Прогноз по всій сітці, отриманий від Open-Meteo в один момент: для кожної точки масиви за годинами.
// Знає лише про себе: свій вік, який відрізок часу покриває й що було в годину idx.
export class GridSnapshot {
  constructor({ fetchedAt, startSec, hours, speed, dir, precip, temp = [] }) {
    this.fetchedAt = fetchedAt; // мс, коли отримано
    this.startSec = startSec; // UNIX-секунди першої години прогнозу
    this.hours = hours; // скільки годин у прогнозі
    this.speed = speed; // [точка][година] — швидкість вітру, м/с
    this.dir = dir; // [точка][година] — напрямок, ° звідки дме
    this.precip = precip; // [точка][година] — опади за попередню годину, мм
    this.temp = temp; // [точка][година] — температура на 2 м, °C
    Object.freeze(this);
  }

  // Відновлення з JSON (дисковий кеш). Чужий або застарілий формат → null, а не зіпсовані дані.
  static fromJSON(raw) {
    const series = ['speed', 'dir', 'precip', 'temp'];
    if (!raw || !Number.isFinite(raw.fetchedAt) || !Number.isFinite(raw.startSec) || !Number.isInteger(raw.hours)) return null;
    if (!series.every((key) => Array.isArray(raw[key]) && raw[key].length > 0)) return null;
    if (new Set(series.map((key) => raw[key].length)).size !== 1) return null; // однакова кількість точок у всіх рядах
    return new GridSnapshot(raw);
  }

  isFresh(nowMs, ttlMs) {
    return nowMs - this.fetchedAt < ttlMs;
  }

  // Копія, яку вважатимемо свіжою ще retryMs: так не б'ємо по сервісу, що не відповідає, на кожен запит
  postponeRefresh(nowMs, ttlMs, retryMs) {
    return new GridSnapshot({ ...this, fetchedAt: nowMs - ttlMs + retryMs });
  }

  // Година 0 — це «зараз», а не початок кешу: кеш міг бути отриманий кілька годин тому, тому
  // початок зсувається до поточної години. Повертає індекс у масивах і скільки годин лишилось.
  locate(nowMs, hour) {
    const base = Math.max(0, Math.floor((nowMs / 1000 - this.startSec) / 3600));
    const idx = base + hour;
    const available = this.hours - base;
    if (idx >= this.hours) throw new ValidationError(`Прогноз доступний лише на ${available} год.`);
    return { idx, available, time: new Date((this.startSec + idx * 3600) * 1000).toISOString() };
  }
}

import { NotFoundError, RateLimitError, UpstreamError } from '../errors.js';

// ШАР 3 — абстрактний Client (патерн «шаблонний метод»). Тут лежить ЗАГАЛЬНИЙ алгоритм запиту:
//   1. зробити запит;  2. мережа впала → UpstreamError;  3. статус не 2xx → помилка за статусом.
// Те, що різниться між сервісами (як вони називаються і які в них тексти помилок), нащадок дає сам,
// перевизначивши serviceName і errorForStatus.
export class ApiClient {
  #fetchFn;

  // fetchFn передається ззовні: у тестах підставляємо підроблений fetch, мережа не потрібна
  constructor({ fetchFn = fetch } = {}) {
    if (new.target === ApiClient) throw new TypeError('ApiClient is abstract: use a subclass');
    this.#fetchFn = fetchFn;
  }

  // ── Що має дати нащадок ──
  get serviceName() {
    throw new Error(`${this.constructor.name} must define serviceName`);
  }

  // context — те, що знає викликач (наприклад, текст для 404). Базова версія — загальні тексти.
  errorForStatus(status, context = {}) {
    if (status === 404) return new NotFoundError(context.notFoundMessage ?? 'Не знайдено.');
    if (status === 429) return new RateLimitError('Перевищено ліміт запитів, спробуй пізніше.');
    return new UpstreamError(`Помилка сервісу ${this.serviceName}.`);
  }

  // ── Загальний алгоритм ──
  async request(url, context) {
    let res;
    try {
      res = await this.#fetchFn(url);
    } catch (err) {
      throw new UpstreamError(`Не вдалося звʼязатися з ${this.serviceName}.`, { cause: err });
    }
    if (!res.ok) throw this.errorForStatus(res.status, context);
    return res;
  }

  async getJson(url, context) {
    return (await this.request(url, context)).json();
  }

  async getBuffer(url, context) {
    return Buffer.from(await (await this.request(url, context)).arrayBuffer());
  }
}

// Клієнт OpenWeatherMap (патерн Adapter). Єдине місце, яке знає, ЯК говорити з цим API:
// URL, параметри, ключ, коди відповідей. Повертає «сирий» JSON або байти тайла.
export class OpenWeatherClient extends ApiClient {
  static BASE_URL = 'https://api.openweathermap.org/data/2.5';
  static TILE_URL = 'https://tile.openweathermap.org/map'; // Weather Maps 1.0

  #apiKey;

  constructor({ apiKey, ...options }) {
    super(options); // fetchFn
    this.#apiKey = apiKey; // приватне: ключ не потрапить у лог чи відповідь випадково
  }

  // ── Перевизначення базового класу (поліморфізм) ──
  get serviceName() {
    return 'OpenWeatherMap';
  }

  errorForStatus(status, context) {
    if (status === 401) {
      return new UpstreamError('API-ключ недійсний або ще не активований (до 2 годин після створення).');
    }
    if (status === 404 || status === 429) return super.errorForStatus(status, context);
    return new UpstreamError('Помилка сервісу погоди.');

  async #fetchWeather(endpoint, query) {

    const q = query.country ? `${query.name},${query.country}` : query.name;
    url.search = new URLSearchParams({ q, appid: this.#apiKey, units: 'metric', lang: 'ua' });

      notFoundMessage: `Місто «${query.name}» не знайдено${query.country ? ` (${query.country})` : ''}.`,
    });
  }

  getCurrent(query) {
    return this.#fetchWeather('weather', query); // поточна погода
  }

  getForecast(query) {
    return this.#fetchWeather('forecast', query); // 5 днів × кожні 3 години
  }

    const url = new URL(`${OpenWeatherClient.TILE_URL}/${tile.layer}/${tile.z}/${tile.x}/${tile.y}.png`);

// ШАР 2 — Service для карт по сітці: анімований вітер і опади.
// Бере прогноз по сітці над Європою ОДНИМ набором запитів до Open-Meteo, кешує його
// (щоб не вичерпати ліміти) і віддає по одній годині у вигляді кадрів:
//   • вітер  → WindFrame ([U, V] для leaflet-velocity);
//   • опади  → PrecipitationFrame (плоский масив мм/год для власного canvas-шару);
//   • температура → TemperatureFrame (плоский масив °C для того ж canvas-шару).
import { ForecastHour } from '../domain/ForecastHour.js';
import { Grid } from '../domain/Grid.js';
import { GridSnapshot } from '../domain/GridSnapshot.js';
import { PrecipitationFrame, TemperatureFrame, WindFrame } from '../domain/Frame.js';
import { WindVector } from '../domain/WindVector.js';
import { UpstreamError } from '../errors.js';

const sleepMs = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
const round2 = (n) => Math.round(n * 100) / 100;
const round1 = (n) => Math.round(n * 10) / 10;

export class GridService {
  static FORECAST_HOURS = 72;
  static CHUNK_SIZE = 100; // точок в одному запиті до Open-Meteo
  static TTL_MS = 3 * 60 * 60 * 1000; // модель оновлюється раз на кілька годин — частіше питати марно
  static RETRY_AFTER_FAIL_MS = 10 * 60 * 1000;

  #client;
  #grid;
  #now;
  #sleep;
  #pauseMs;
  #snapshot = null; // GridSnapshot у памʼяті
  #inflight = null; // Promise оновлення, що вже виконується
  #store;
  #restored = false; // чи вже пробували підняти знімок із диска

  // store — необовʼязковий дисковий кеш (load/save); без нього знімок живе лише в памʼяті
  constructor({ client, grid = Grid.EUROPE, now = Date.now, sleep = sleepMs, pauseMs = 1000, store = null }) {
    this.#client = client;
    this.#store = store;
    this.#grid = grid;
    this.#now = now;
    this.#sleep = sleep; // у тесті «сон» миттєвий
    this.#pauseMs = pauseMs;
  }

  // hour = 0 — поточна година, 1 — наступна і т.д.
  async getWindFrame(rawHour) {
    const { snapshot, idx, meta } = await this.#locate(rawHour);
    const u = [];
    const v = [];
    for (let p = 0; p < snapshot.speed.length; p++) {
      const wind = WindVector.fromMeteo(snapshot.speed[p][idx] ?? 0, snapshot.dir[p][idx] ?? 0);
      u.push(round2(wind.u));
      v.push(round2(wind.v));
    }
    return WindFrame.of(meta, this.#grid, u, v);
  }

  // Опади за годину, мм (Open-Meteo: сума за попередню годину). Немає даних → 0.
  async getPrecipitationFrame(rawHour) {
    const { snapshot, idx, meta } = await this.#locate(rawHour);
    const values = snapshot.precip.map((series) => round2(series[idx] ?? 0));
    return new PrecipitationFrame(meta, this.#grid.describe(), values);
  }

  // Температура на 2 м, °C. Немає даних → null (0 °C — теж температура, її підставляти не можна).
  async getTemperatureFrame(rawHour) {
    const { snapshot, idx, meta } = await this.#locate(rawHour);
    const values = snapshot.temp.map((series) => (Number.isFinite(series[idx]) ? round1(series[idx]) : null));
    return new TemperatureFrame(meta, this.#grid.describe(), values);
  }

  // Спільна частина для всіх кадрів: перевірка години, свіжий знімок, зсув до поточної години
  async #locate(rawHour) {
    const hour = ForecastHour.parse(rawHour).value;
    const snapshot = await this.#freshSnapshot();
    const { idx, available, time } = snapshot.locate(this.#now(), hour);
    return { snapshot, idx, meta: { hour, hours: available, time } };
  }

  // Свіжий знімок → віддаємо. Інакше оновлюємо; кілька одночасних запитів ділять один запит назовні.
  async #freshSnapshot() {
    await this.#restore();
    if (this.#snapshot?.isFresh(this.#now(), GridService.TTL_MS)) return this.#snapshot;
    this.#inflight ??= this.#download()
      .then(async (fresh) => {
        this.#snapshot = fresh;
        await this.#store?.save(fresh);
        return fresh;
      })
      .catch((err) => {
        if (!this.#snapshot) throw err;
        // Є старий знімок: лишаємо його й пробуємо знову за 10 хвилин, а не на кожен запит
        this.#snapshot = this.#snapshot.postponeRefresh(this.#now(), GridService.TTL_MS, GridService.RETRY_AFTER_FAIL_MS);
        return this.#snapshot;
      })
      .finally(() => { this.#inflight = null; });
    return this.#inflight;
  }

  // Одноразово, перед першим запитом: беремо знімок із диска, якщо він ще свіжий і підходить до нашої сітки
  async #restore() {
    if (this.#restored || !this.#store) return;
    this.#restored = true;
    const saved = await this.#store.load();
    const fits = saved && saved.speed.length === this.#grid.pointCount;
    if (fits && saved.isFresh(this.#now(), GridService.TTL_MS)) this.#snapshot = saved;
  }

  async #download() {
    const points = this.#grid.points();
    const speed = [];
    const dir = [];
    const precip = [];
    const temp = [];
    let times = null;

    for (let i = 0; i < points.length; i += GridService.CHUNK_SIZE) {
      if (i > 0) await this.#sleep(this.#pauseMs); // не частимо: ліміт 600 викликів на хвилину
      const chunk = points.slice(i, i + GridService.CHUNK_SIZE);
      const results = await this.#client.getGrid(chunk, GridService.FORECAST_HOURS);
      if (results.length !== chunk.length) throw new UpstreamError('Open-Meteo повернув неповні дані.');

      for (const r of results) {
        times ??= r.hourly.time;
        speed.push(r.hourly.wind_speed_10m);
        dir.push(r.hourly.wind_direction_10m);
        precip.push(r.hourly.precipitation);
        temp.push(r.hourly.temperature_2m);
      }
    }
    return new GridSnapshot({ fetchedAt: this.#now(), startSec: times[0], hours: times.length, speed, dir, precip, temp });
  }
}

// Маршрутизатор: за шляхом запиту обирає обробника (контролер) і викликає його handle(req, res, ctx).
// Нічого не знає про те, що саме роблять контролери: працює з будь-яким обʼєктом, який має handle.
export class Router {
  #routes = [];
  #fallback;

  // fallback — обробник для всього, що не збіглося з маршрутами (у нас це роздача статичних файлів)
  constructor({ fallback }) {
    this.#fallback = fallback;
  }

  // pattern: рядок (точний збіг) або RegExp (групи потрапляють у ctx.params). Повертає this: можна ланцюжком.
  get(pattern, controller) {
    this.#routes.push({ pattern, controller });
    return this;
  }

  #match(pathname) {
    for (const { pattern, controller } of this.#routes) {
      if (typeof pattern === 'string') {
        if (pattern === pathname) return { controller, params: [] };
      } else {
        const m = pathname.match(pattern);
        if (m) return { controller, params: m.slice(1) };
      }
    }
    return null;
  }

  async handle(req, res) {
    try {
      const url = new URL(req.url, `http://${req.headers.host}`);
      if (req.method !== 'GET') return void res.writeHead(405).end();
      const { controller, params } = this.#match(url.pathname) ?? { controller: this.#fallback, params: [] };
      await controller.handle(req, res, { url, params });
    } catch (err) {
      // Страховка: контролери ловлять свої помилки самі, але некоректний запит (напр., дивний Host) не має валити сервер
      console.error(err);
      if (!res.headersSent) res.writeHead(400);
      res.end();
    }
  }
}

import { readFile } from 'node:fs/promises';
import path from 'node:path';

// Роздача файлів із public/. Має той самий метод handle(req, res, ctx), що й контролери,
// тож Router викликає його однаково (поліморфізм: «щось, що вміє handle»).
export class StaticHandler {
  static MIME = {
    '.html': 'text/html; charset=utf-8',
    '.css': 'text/css; charset=utf-8',
    '.js': 'text/javascript; charset=utf-8',
  };

  #publicDir;

  constructor(publicDir) {
    this.#publicDir = publicDir;
  }

  async handle(req, res, { url }) {
    let rel;
    try {
      rel = url.pathname === '/' ? '/index.html' : decodeURIComponent(url.pathname);
    } catch {
      res.writeHead(400).end('Bad request'); // некоректне %-кодування (наприклад, /%zz)
      return;
    }
    const file = path.normalize(path.join(this.#publicDir, rel));

    if (!file.startsWith(this.#publicDir + path.sep)) {
      res.writeHead(403).end('Forbidden'); // захист від ../ (path traversal)
      return;
    }
    try {
      const body = await readFile(file);
      res.writeHead(200, { 'Content-Type': StaticHandler.MIME[path.extname(file)] || 'application/octet-stream' });
      res.end(body);
    } catch {
      res.writeHead(404).end('Not found');
    }
  }
}

//        └─ ScalarFieldSource     — число на вузол сітки (власний canvas-шар) зі своєю палітрою

//   Timeline        — повзунок часу і кнопка ▶

const $ = (id) => document.getElementById(id);
const round = (n) => Math.round(n);
const iconUrl = (code) => `https://openweathermap.org/img/wn/${code}@2x.png`;

// ── Обмін з сервером ────────────────────────────────────────────
class WeatherApi {
  // Відповідь сервера — JSON; при помилці в ньому поле error. fallback — текст, якщо його нема.
  async #getJson(url, fallback) {
    const res = await fetch(url);
    const body = await res.json();
    if (!res.ok) throw new Error(body.error || fallback);
    return body;
  }

  weather(city, country = '') {
    const params = new URLSearchParams({ city });
    if (country) params.set('country', country);
    return this.#getJson(`/api/weather?${params}`, 'Щось пішло не так.');
  }

  // Кадр прогнозу на годину hour; url і title дає джерело шару
  frame(url, hour, title) {
    return this.#getJson(`${url}?hour=${hour}`, `Не вдалося завантажити: ${title}.`);
  }

  async countries() {
    const res = await fetch('/api/countries');
    if (!res.ok) throw new Error(String(res.status));
    return res.json();
  }
}

// Підложка — стандартні тайли OpenStreetMap (без ключа), у темній темі через CSS-фільтр.
// Шари погоди бувають двох видів:
//  • тайли-картинки з НАШОГО сервера (/api/tiles/...) — сервер додає API-ключ, у браузері його немає;
//  • «кадрові» шари з прогнозом по годинах: сервер віддає кадр на годину N, а браузер малює його
//    (вітер — leaflet-velocity, опади й температура — власний canvas-шар). Керує ними повзунок часу.
// WeatherMap працює з будь-яким LayerSource однаково: поліморфізм замість if/else за назвою шару.
class LayerSource {
  constructor(name, hint) {
    if (new.target === LayerSource) throw new TypeError('LayerSource is abstract: use a subclass');
    this.name = name; // значення data-layer кнопки
    this.hint = hint; // підказка під картою
  }

  get isFrame() {
    return false;
  }

  // Палітра для легенди (з FieldPalettes) або null, якщо шар легенди не має
  get palette() {
    return null;
  }

  createLayer() {
    throw new Error(`${this.constructor.name} must implement createLayer()`);
  }
}

class TileSource extends LayerSource {
  createLayer() {
    return L.tileLayer(`/api/tiles/${this.name}/{z}/{x}/{y}.png`, { opacity: 0.8, maxNativeZoom: 10, maxZoom: 12 });
  }
}

class FrameSource extends LayerSource {
  constructor(name, hint, { url, title }) {
    super(name, hint);
    this.url = url; // звідки брати кадр
    this.title = title; // для повідомлень: «Завантажую: вітер…»
  }

  get isFrame() {
    return true;
  }

  load(api, hour) {
    return api.frame(this.url, hour, this.title);
  }

  // body — відповідь сервера (кадр). createLayer створює шар, updateLayer міняє дані в уже створеному.
  updateLayer() {
    throw new Error(`${this.constructor.name} must implement updateLayer()`);
  }
}

class WindSource extends FrameSource {

    });
  }

  updateLayer(layer, body) {
    layer.setData(body.data);
  }
}

// Спільне для шарів «одне число на вузол сітки»: різняться вони лише адресою, текстами й палітрою
class ScalarFieldSource extends FrameSource {

}

// Легенда шару з палітрою: кольорові «плашки» зі шкали. Будується з палітри (звичайні дані), а не з шару Leaflet,

class Legend {
  #box = $('legend');
  #title = $('legend-title');
  #scale = $('legend-scale');

  show(palette) {
    this.#box.hidden = !palette;
    if (!palette) return;
    this.#title.textContent = palette.title;
    const stops = palette.skipFirstInLegend ? palette.stops.slice(1) : palette.stops;
    const cells = stops.map(([value, r, g, b], i) => {
      const cell = document.createElement('span');
      cell.style.background = `rgb(${r}, ${g}, ${b})`;
      cell.textContent = `${value}${i === stops.length - 1 ? palette.legendSuffix : ''}`;
      return cell;
    });
    this.#scale.replaceChildren(...cells);
  }
}

class Timeline {
  static DEBOUNCE_MS = 200;
  static PLAY_STEP_MS = 1000;

  #box = $('timeline');
  #slider = $('hour');
  #playBtn = $('play');
  #label = $('hour-label');
  #playTimer = null;
  #debounce = null;

  // onChange(hour) — що робити, коли користувач (або ▶) вибрав нову годину
  constructor({ onChange }) {
    this.#slider.addEventListener('input', () => {
      clearTimeout(this.#debounce); // не засипаємо сервер запитами, поки рухаєш повзунок
      this.#debounce = setTimeout(() => onChange(this.hour), Timeline.DEBOUNCE_MS);
    });

    this.#playBtn.addEventListener('click', () => {
      if (this.#playTimer) return this.stop();
      this.#playBtn.textContent = '⏸';
      this.#playBtn.setAttribute('aria-label', 'Пауза');
      this.#playTimer = setInterval(() => {
        const next = (this.hour + 1) % (Number(this.#slider.max) + 1);
        this.#slider.value = String(next);
        onChange(next);
      }, Timeline.PLAY_STEP_MS);
    });
  }

  static #formatHour(iso) {
    return new Date(iso).toLocaleString('uk-UA', { weekday: 'short', day: 'numeric', month: 'short', hour: '2-digit', minute: '2-digit' });
  }

  get hour() {
    return Number(this.#slider.value);
  }

  setVisible(visible) {
    this.#box.hidden = !visible;
  }

  // hours — скільки годин прогнозу лишилось, time — ISO-час поточного кадру
  update(hours, time) {
    this.#slider.max = String(hours - 1);
    this.#label.textContent = Timeline.#formatHour(time);
  }

  stop() {
    clearInterval(this.#playTimer);
    this.#playTimer = null;
    this.#playBtn.textContent = '▶';
    this.#playBtn.setAttribute('aria-label', 'Відтворити');
  }
}

// ── Карта (Leaflet) ─────────────────────────────────────────────
class WeatherMap {
  #api;
  #sources; // Map: назва шару → LayerSource
  #timeline;
  #switcher;
  #legend;
  #section = $('map-section');
  #hint = $('map-hint');
  #map = null;
  #marker = null;
  #layer = null; // шар-тайли АБО velocity/canvas-шар (одночасно лише один)
  #active;
  #frameSeq = 0; // номер останнього запиту кадру: відповіді-«запізненці» ігноруємо

  constructor({ api, sources, initial, timeline, switcher, legend }) {
    this.#api = api;
    this.#sources = new Map(sources.map((s) => [s.name, s]));
    this.#active = initial;
    this.#timeline = timeline;
    this.#switcher = switcher;
    this.#legend = legend;
    switcher.onSelect((name) => this.setLayer(name));
  }

  get #source() {
    return this.#sources.get(this.#active);
  }

  hide() {
    this.#section.hidden = true;
  }

  setLayer(name) {
    this.#active = name;
    const source = this.#source;
    this.#switcher.setActive(name);
    this.#hint.textContent = source.hint;
    this.#timeline.setVisible(source.isFrame);
    this.#legend.show(source.palette);
    this.#timeline.stop();
    this.#frameSeq++; // скасовує відповіді попередніх запитів
    if (!this.#map) return;

    if (this.#layer) this.#map.removeLayer(this.#layer);
    this.#layer = null;
    if (source.isFrame) this.loadFrame(this.#timeline.hour);
    else this.#layer = source.createLayer().addTo(this.#map);
  }

  async loadFrame(hour) {
    const source = this.#source;
    const seq = ++this.#frameSeq;
    // Перший запит за ~3 години заповнює кеш на сервері (кілька порцій до Open-Meteo) — це займає кілька секунд
    if (!this.#layer) this.#hint.textContent = `Завантажую: ${source.title}… (перший раз це кілька секунд)`;
    try {
      const body = await source.load(this.#api, hour);
      if (seq !== this.#frameSeq || this.#source !== source || !this.#map) return; // користувач вже перейшов далі

      this.#timeline.update(body.hours, body.time);
      if (this.#layer) source.updateLayer(this.#layer, body);
      else this.#layer = source.createLayer(body).addTo(this.#map);
      this.#hint.textContent = source.hint;
    } catch (err) {
      if (seq !== this.#frameSeq) return;
      this.#timeline.stop();
      this.#hint.textContent = `${source.title[0].toUpperCase()}${source.title.slice(1)}: ${err.message}`;
    }
  }

  // Показує карту в точці міста. Кидає помилку, якщо координат нема: App сам вирішує, що з цим робити.
  show({ lat, lon, city }) {
    if (typeof L === 'undefined') return; // Leaflet не завантажився (немає інтернету до CDN)
    if (!Number.isFinite(lat) || !Number.isFinite(lon)) throw new Error('Сервер не повернув координати (перезапусти його).');
    this.#section.hidden = false; // спершу показуємо блок — Leaflet має знати розмір контейнера

    if (!this.#map) {
      this.#map = L.map('map', { worldCopyJump: true }).setView([lat, lon], 6);
      L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
        maxZoom: 12,
        className: 'base-tiles', // у style.css цей шар затемнюється фільтром
        attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> | Погода: <a href="https://openweathermap.org">OpenWeatherMap</a>',
      }).addTo(this.#map);
      this.#marker = L.marker([lat, lon]).addTo(this.#map);
      this.setLayer(this.#active);
    } else {
      this.#map.setView([lat, lon], this.#map.getZoom());
      this.#marker.setLatLng([lat, lon]);
    }
    this.#marker.bindTooltip(city);
    this.#map.invalidateSize();
  }
}

class App {
  #form = $('search');
  #input = $('city');
  #api = new WeatherApi();
  #view = new WeatherView();

    const timeline = new Timeline({ onChange: (hour) => this.#map.loadFrame(hour) });
    const legend = new Legend();
    this.#map = new WeatherMap({
      api: this.#api,
      sources: [
        new WindSource(),
        new PrecipitationSource(),
        new TemperatureSource(),
        new TileSource('precipitation_new', 'Опади зараз (OpenWeatherMap): від світлого (слабкі) до насиченого (сильні).'),
        new TileSource('clouds_new', 'Хмарність: чим біліше й щільніше, тим більше хмар.'),
        new TileSource('wind_new', 'Швидкість вітру: чим насиченіший колір, тим сильніший вітер.'),
        new TileSource('temp_new', 'Температура повітря: холодні тони → теплі.'),
        new TileSource('pressure_new', 'Атмосферний тиск: низький та високий — різні кольори.'),
      ],
      initial: 'wind_anim',
      timeline,
      switcher: new LayerSwitcher(),
      legend,
    });
  }

  start() {
    this.#map.setLayer('wind_anim'); // підказка й повзунок видно ще до першого пошуку; карти ще нема
    this.#form.addEventListener('submit', (e) => {
      e.preventDefault();
      const city = this.#input.value.trim();
      if (city) this.search(city, this.#countries.value);
    });

    this.#countries.load().then(() => {
      const last = this.#history.lastCity;
      if (last) {
        this.#input.value = last;
        this.search(last, this.#countries.value);
      }
    });
  }

  async search(city, country = '') {
    const button = this.#form.querySelector('button');
    button.disabled = true;
    this.#view.setStatus('Завантаження…');

    try {
      const data = await this.#api.weather(city, country);
      this.#view.showCurrent(data);
      this.#view.showForecast(data.forecast);
      this.#view.setStatus('');
      // Карта — додаткова: якщо з нею щось не так, погода й пошук мають працювати далі
      try {
        this.#map.show({ ...data.coord, city: data.city });
      } catch (mapErr) {
        console.error('Карта не відобразилась:', mapErr);
        this.#map.hide();
      }
      this.#history.save(city, country);
    } catch (err) {
      this.#view.hideAll();
      this.#map.hide();
      this.#view.setStatus(err.message, true);
    } finally {
      button.disabled = false;
    }
  }
}

Тепер у WeatherMap.setLayer() немає жодної назви шару: він питає у джерела isFrame, palette, hint і викликає createLayer() / updateLayer(). Додати шар значить написати ще один клас-нащадок: так з'явився TemperatureSource (≈10 рядків, бо спільне лежить у ScalarFieldSource).
  • Палітра — це дані, а не код Leaflet. window.FieldPalettes оголошено в scalarFieldLayer.js до перевірки typeof L, тож Legend.show(palette) працює, навіть якщо Leaflet не завантажився. Саме так усунуто ReferenceError, описаний у розділі 11.
  • Абстрактні LayerSource і FrameSource не можна створити напряму; тайловий і кадрові шари відрізняються тим, що перші не мають load() і повзунка.
  • Одна відповідальність на клас. WeatherApi — єдине місце з fetch; WeatherView лише малює; Timeline керує повзунком і кнопкою ▶; SearchHistory — єдиний, хто знає про localStorage.

  • Захист від «запізнілих» відповідей збережено. #frameSeq збільшується при кожному запиті й перемиканні шару; відповідь, номер якої застарів, ігнорується. Debounce повзунка 200 мс і крок відтворення 1 с стали константами Timeline.
  • Карта — додаткова. App.search() обгортає map.show() у власний try/catch: помилка карти ховає лише карту, а погода й пошук працюють.
  • Приватні поля й this. Обробники подій у конструкторах — стрілкові функції, тому this лишається класом.

// Бере прогноз по сітці над Європою ОДНИМ набором запитів до Open-Meteo, кешує його
// (щоб не вичерпати ліміти) і віддає по одній годині:
//   • вітер  → [U, V] у форматі leaflet-velocity;
//   • опади  → плоский масив мм/год + опис сітки для власного canvas-шару.
import { AppError } from '../errors.js';

// Сітка: рядки йдуть з ПІВНОЧІ на південь, колонки — із заходу на схід (так вимагає leaflet-velocity).
export const GRID = { la1: 72.5, la2: 32.5, lo1: -25, lo2: 45, step: 2.5 };

const FORECAST_HOURS = 72;
const CHUNK_SIZE = 100; // точок в одному запиті до Open-Meteo
const TTL_MS = 3 * 60 * 60 * 1000; // модель оновлюється раз на кілька годин — частіше питати марно
const RETRY_AFTER_FAIL_MS = 10 * 60 * 1000;

const round2 = (n) => Math.round(n * 100) / 100;

export function gridSize(grid = GRID) {
  return {
    ny: Math.round((grid.la1 - grid.la2) / grid.step) + 1,
    nx: Math.round((grid.lo2 - grid.lo1) / grid.step) + 1,
  };
}

// Опис сітки для клієнта: з нього він знає, де лежить кожне значення масиву.
export function gridInfo(grid = GRID) {
  const { nx, ny } = gridSize(grid);
  return { la1: grid.la1, la2: grid.la2, lo1: grid.lo1, lo2: grid.lo2, dx: grid.step, dy: grid.step, nx, ny };
}

// Усі точки сітки в порядку даних: рядок за рядком, з північного заходу.
export function gridPoints(grid = GRID) {
  const { ny, nx } = gridSize(grid);
  const points = [];
  for (let r = 0; r < ny; r++) {
    for (let c = 0; c < nx; c++) {
      points.push({ lat: grid.la1 - r * grid.step, lon: grid.lo1 + c * grid.step });
    }
  }
  return points;
}

// Метеорологічний напрямок — ЗВІДКИ дме вітер (0° = північний, дме на південь).
// U — на схід, V — на північ.
export function toUV(speed, directionDeg) {
  const rad = (directionDeg * Math.PI) / 180;
  return { u: -speed * Math.sin(rad), v: -speed * Math.cos(rad) };
}

// Збирає два «GRIB-подібні» обʼєкти (U і V) для leaflet-velocity з масивів значень сітки.
export function buildVelocityData(uValues, vValues, refTimeIso, grid = GRID) {
  const { lo1, lo2, la1, la2, dx, dy, nx, ny } = gridInfo(grid);
  const header = (parameterNumber, parameterNumberName) => ({
    parameterCategory: 2, parameterNumber, parameterNumberName, parameterUnit: 'm.s-1',
    lo1, lo2, la1, la2, dx, dy, nx, ny, refTime: refTimeIso,
  });
  return [
    { header: header(2, 'U-component_of_wind'), data: uValues },
    { header: header(3, 'V-component_of_wind'), data: vValues },
  ];
}

const sleepMs = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

export function createGridService({ client, now = Date.now, sleep = sleepMs, pauseMs = 1000 }) {
  let cache = null; // { fetchedAt, startSec, hours, speed, dir, precip } — масиви по точках
  let inflight = null;

  async function fetchGrid() {
    const points = gridPoints();
    const speed = [];
    const dir = [];
    const precip = [];
    let times = null;

    for (let i = 0; i < points.length; i += CHUNK_SIZE) {
      if (i > 0) await sleep(pauseMs); // не частимо: ліміт 600 викликів на хвилину
      const chunk = points.slice(i, i + CHUNK_SIZE);
      const results = await client.getGrid(chunk, FORECAST_HOURS);
      if (results.length !== chunk.length) throw new AppError(502, 'Open-Meteo повернув неповні дані.');

      for (const r of results) {
        times ??= r.hourly.time;
        speed.push(r.hourly.wind_speed_10m);
        dir.push(r.hourly.wind_direction_10m);
        precip.push(r.hourly.precipitation);
      }
    }
    return { fetchedAt: now(), startSec: times[0], hours: times.length, speed, dir, precip };
  }

  // Свіжий кеш → віддаємо. Інакше оновлюємо; кілька одночасних запитів ділять один запит назовні.
  async function ensureFresh() {
    if (cache && now() - cache.fetchedAt < TTL_MS) return cache;
    inflight ??= fetchGrid()
      .then((fresh) => (cache = fresh))
      .catch((err) => {
        if (!cache) throw err;
        cache = { ...cache, fetchedAt: now() - TTL_MS + RETRY_AFTER_FAIL_MS }; // лишаємо старе, спробуємо пізніше
        return cache;
      })
      .finally(() => { inflight = null; });
    return inflight;
  }

  // Спільна частина для всіх кадрів: перевірка години, зсув від початку кешу, час кадру.
  async function locate(rawHour) {
    const hour = Number(rawHour ?? 0);
    if (!Number.isInteger(hour) || hour < 0) throw new AppError(400, 'Некоректна година прогнозу.');

    const c = await ensureFresh();
    // Кеш міг зʼявитись кілька годин тому: зсуваємо початок до поточної години
    const base = Math.max(0, Math.floor((now() / 1000 - c.startSec) / 3600));
    const idx = base + hour;
    const available = c.hours - base;
    if (idx >= c.hours) throw new AppError(400, `Прогноз доступний лише на ${available} год.`);

    const time = new Date((c.startSec + idx * 3600) * 1000).toISOString();
    return { c, hour, idx, meta: { hour, hours: available, time } };
  }

  return {
    // hour = 0 — поточна година, 1 — наступна і т.д.
    async getWindFrame(rawHour) {
      const { c, idx, meta } = await locate(rawHour);
      const u = [];
      const v = [];
      for (let p = 0; p < c.speed.length; p++) {
        const wind = toUV(c.speed[p][idx] ?? 0, c.dir[p][idx] ?? 0);
        u.push(round2(wind.u));
        v.push(round2(wind.v));
      }
      return { ...meta, data: buildVelocityData(u, v, meta.time) };
    },

    // Опади за годину, мм (Open-Meteo: сума за попередню годину). Немає даних → 0.
    async getPrecipitationFrame(rawHour) {
      const { c, idx, meta } = await locate(rawHour);
      const values = c.precip.map((series) => round2(series[idx] ?? 0));
      return { ...meta, grid: gridInfo(), values };
    },
  };
}

}

async function loadWeather(city, country = '') {
  const button = form.querySelector('button');
  button.disabled = true;
  setStatus('Завантаження…');

  try {
    const params = new URLSearchParams({ city });
    if (country) params.set('country', country);
    const res = await fetch(`/api/weather?${params}`);
    const data = await res.json();
    if (!res.ok) throw new Error(data.error || 'Щось пішло не так.');

    renderCurrent(data);
    renderForecast(data.forecast);
    setStatus('');
    // Карта — додаткова: якщо з нею щось не так, погода й пошук мають працювати далі

      $('map-section').hidden = true;
    }

    localStorage.setItem('lastCountry', country);

    $('forecast').hidden = true;
    $('map-section').hidden = true;
    setStatus(err.message, true);
  } finally {
    button.disabled = false;
  }
}
